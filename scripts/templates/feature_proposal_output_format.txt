必ず有効なJSONだけを出力してください。
Markdown、コードブロック、説明文、前置き、後書きは出力しないでください。

JSONのトップレベルは以下の構造にしてください。

{
  "title": "AI機能提案",
  "appUnderstanding": [
    "READMEから読み取れるアプリ概要を3〜5行で要約してください。"
  ],
  "selectionGuide": {
    "description": "実装する候補はIssueNoで指定できます。",
    "examples": [
      "FP-001",
      "FP-001, FP-003"
    ]
  },
  "issues": [
    {
      "issueNo": "FP-001",
      "selected": false,
      "featureName": "",
      "summary": "",
      "problem": "",
      "proposal": "",
      "userValue": "",
      "implementationDifficulty": "🟩 Low",
      "priority": "P0",
      "estimatedScope": "0.5d",
      "suggestedIssueTitle": "",
      "suggestedLabels": [
        "feature"
      ],
      "acceptanceCriteria": [
        ""
      ],
      "implementationNotes": [
        ""
      ]
    }
  ],
  "priorityRanking": [
    {
      "rank": 1,
      "issueNo": "FP-001",
      "reason": ""
    }
  ],
  "deferredIdeas": [
    ""
  ],
  "issueCreationCommandExample": "create issues: FP-001, FP-003"
}

出力ルール:
- `issues`は5〜7件にしてください。
- `issueNo`は必ず`FP-001`から始め、`FP-002`, `FP-003`のように連番にしてください。
- `issues`の各要素は1機能1Issueの粒度にしてください。
- `selected`は必ず`false`にしてください。
- `implementationDifficulty`は必ず`🟩 Low`、`🟨 Middle`、`🟥 High`のいずれかにしてください。
- `priority`は必ず`P0`、`P1`、`P2`のいずれかにしてください。
- `estimatedScope`は必ず`0.5d`、`1d`、`2d`のいずれかにしてください。
- `suggestedLabels`、`acceptanceCriteria`、`implementationNotes`は必ず文字列配列にしてください。
- 日本語ユーザーが読みやすいように、値は原則として日本語で書いてください。
- GitHub Issue作成に使うため、`suggestedIssueTitle`はそのままIssueタイトルに使える短い文にしてください。
