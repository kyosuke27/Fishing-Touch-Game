# AI機能提案

## アプリ理解
READMEから読み取れるアプリ概要を3〜5行で要約してください。

## 選択方法
実装する候補は、以下のIssueNoで指定できる形式にしてください。

例:
- `FP-001`
- `FP-001, FP-003`

## 提案Issue一覧
以下の形式を厳守してください。
IssueNoは必ず`FP-001`から始め、連番にしてください。
Issue化しやすいように、各候補は1機能1Issueの粒度にしてください。

<!-- issue:start FP-001 -->
### IssueNo: FP-001
- [ ] 選択: FP-001
- 機能名:
- 概要:
- 課題:
- 提案内容:
- ユーザー価値:
- 実装難易度: 🟩 Low / 🟨 Middle / 🟥 High
- 優先度: P0 / P1 / P2
- 想定工数: 0.5d / 1d / 2d
- Issueタイトル案:
- ラベル案:
- 受け入れ条件:
  - 
- 実装メモ:
  - 
<!-- issue:end FP-001 -->

提案数は5〜7件にしてください。

## 優先順位
IssueNoで優先順位を書いてください。

例:
1. FP-001: 理由
2. FP-002: 理由

## 今回は見送る案
今すぐIssue化しない案を箇条書きで書いてください。

## Issue作成コマンド例
ユーザーが次に入力しやすいように、最後に以下の形式で例を出してください。

```text
create issues: FP-001, FP-003
```
