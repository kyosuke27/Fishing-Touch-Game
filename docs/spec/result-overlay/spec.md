# spec.md — Result Overlay Asset Refresh

## 概要
- `FishingScreen` で使用している `ResultOverlay` の見た目を画像ベースUIへ変更する
- 成功時の情報配置を見直し、魚名を主役にした構成へ変更する
- 既存の結果判定ロジックは維持し、表示だけを差し替える

## 目的
- 結果オーバーレイをアセットデザインに合わせる
- 釣果結果の視線導線を整理する
- ボタンと補助情報の視認性を上げる

## 対象
- `ResultOverlay.swift`
- 成功時の結果表示レイアウト
- 結果オーバーレイ内のアクションボタン表示

## 対象外
- 釣り成功 / 失敗の判定ロジック変更
- コイン付与や図鑑登録処理の変更
- 魚図鑑画面そのもののUI変更

## 使用アセット
- 図鑑NEW表示: `New`
- 再挑戦ボタン: `RetryFishing`
- ホームへ戻るボタン: `HomeButton`
- コインアイコン: `Coin`

## 成功時レイアウト仕様
### 表示順
- 先頭の主見出しは「釣れた！」ではなく魚名を表示する
- 魚名の下にレア度を表す星を表示する
- 星の下に魚画像を表示する
- その下に重量、獲得コイン、図鑑状態、必要なら記録更新情報を表示する

### 図鑑状態
- 図鑑状態の文言は `新規登録` または `✅` とする
- 既存登録済みの状態は `✅` のみを表示する
- 新規登録時は図鑑状態の左上に `New` 画像を重ねて表示する

### コイン表示
- 獲得コインの金額の左に `Coin` アイコンを表示する
- コインアイコンと数値は同一行で表示する

## 失敗時レイアウト仕様
- 既存の失敗状態表示は維持してよい
- 必要に応じて成功時のボタンデザインに合わせて下部ボタンのみ共通化する

## ボタン仕様
- テキストベースのボタンスタイルは使用しない
- `もう一度釣る` は `RetryFishing` 画像をそのままボタンとして使用する
- `ホームへ戻る` は `HomeButton` 画像をそのままボタンとして使用する
- ボタン上に追加テキストは重ねない
- 無効状態が必要な場合は透明度で表現する

## 表示ルール
- 既存の `glassCard` ベースのオーバーレイ土台は維持してよい
- 成功時の情報量が増えてもオーバーレイ内で収まるように縦方向レイアウトを調整する
- 魚画像、NEW画像、コインアイコンは既存アセット名で参照する

## 実装方針
- `ResultOverlay.swift` を中心に修正する
- 共通化が必要な場合のみ補助コンポーネントを `Presentation/Feature/Fishing/Components/` に追加する
- 結果種別ごとの表示分岐は既存の `FishingResult` 分岐を継続利用する
- 表示変更は成功時レイアウトを優先し、失敗時は必要最小限の調整に留める

## 完了条件
- 成功時に魚名 → 星 → 魚画像の順で表示される
- 図鑑状態の既存登録済みが `✅` 表示になる
- 新規登録時に `New` 画像が図鑑状態の左上に表示される
- 獲得コイン行の左に `Coin` アイコンが表示される
- 下部ボタンが `RetryFishing` と `HomeButton` の画像ボタンに置き換わる
