# 餌購入・所持数管理 Spec

## 目的

- ショップ画面で扱う餌を 6 種に拡張する。
- 餌ごとに画像アセットとレア度を持たせ、UI 表示に利用する。
- 餌の管理方式を「解放済み」から「所持数」へ変更する。

## 前提

- 餌は購入 1 回ごとに 1 個増える。
- 今回の修正範囲では、釣り実行時に餌を消費しない。
- 餌画像はすべて `Assets.xcassets` に配置済みである。

## データ構造

- `BaitMaster`
  - `rarity` を追加する。
  - `imageName` を追加し、アセット名を保持する。
- `UserGameData`
  - `baitQuantities: [String: Int]` を保持する。

## 購入・選択仕様

- 購入時
  - 所持コインが価格以上であれば購入できる。
  - 購入 1 回で対象餌の所持数を `+1` する。
  - 所持済みでも追加購入できる。
- 選択時
  - 所持数が `1` 以上の餌のみ選択できる。

## UI 仕様

- `HomeScreen`
  - 選択中餌の画像は `BaitMaster.imageName` を使う。
- `FishingScreen`
  - 選択中餌の画像は `BaitMaster.imageName` を使う。
- `ShopScreen`
  - 餌画像をアセット画像で表示する。
  - レア度を星で表示する。
  - 価格を表示する。
  - 所持数を表示する。
  - 所持数が 1 以上なら選択できる。
  - 選択中でも追加購入できる。

## 保存形式

- ユーザーデータの餌所持情報は `baitQuantities` のみで管理する。
